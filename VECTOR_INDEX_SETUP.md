# MongoDB Atlas Vector Search Setup Guide

This document explains how to set up the Vector Search index in MongoDB Atlas for the AI Catalog SaaS Platform.

## 1. Prerequisites
- MongoDB Atlas cluster running MongoDB 6.0+ (Atlas Search requires Atlas deployment).
- Database name: Configured via `MONGO_DB` in `.env` (e.g., `ai_catalog_db`).
- Collection name: `catalogitems` (the collection generated by the `CatalogItem` model).

---

## 2. Create Vector Search Index in MongoDB Atlas UI

1. Open **MongoDB Atlas** and navigate to your Cluster.
2. Click on **Atlas Search** (or **Search / Vector Search** tab).
3. Click **Create Search Index**.
4. Select **JSON Editor** under **Atlas Vector Search** and click **Next**.
5. Select your Database (e.g. `ai_catalog_db`) and Collection (`catalogitems`).
6. Name the Index: `vector_index` (Must match the index name specified in `retrieval.service.js`).
7. Paste the following JSON definition into the editor:

```json
{
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 1536,
      "similarity": "cosine"
    },
    {
      "type": "filter",
      "path": "tenantId"
    },
    {
      "type": "filter",
      "path": "catalogId"
    },
    {
      "type": "filter",
      "path": "isAvailable"
    }
  ]
}
```

8. Click **Save Changes** / **Create Vector Search Index**.
9. Wait for the index status to become **Active**.

---

## 3. How Vector Search Operates in Code

The backend executes the MongoDB `$vectorSearch` pipeline stage scoped strictly to the current tenant:

```javascript
[
  {
    $vectorSearch: {
      index: 'vector_index',
      path: 'embedding',
      queryVector: queryEmbedding,
      numCandidates: 50,
      limit: limit,
      filter: {
        tenantId: new mongoose.Types.ObjectId(tenantId),
        catalogId: new mongoose.Types.ObjectId(catalogId),
        isAvailable: true
      }
    }
  },
  {
    $project: {
      name: 1,
      description: 1,
      price: 1,
      currency: 1,
      category: 1,
      tags: 1,
      attributes: 1,
      ingredients: 1,
      score: { $meta: 'vectorSearchScore' }
    }
  }
]
```

---

## 4. Fallback Mode for Local Development

If MongoDB Atlas Vector Search is not enabled on a local MongoDB instance, the application includes a fallback text & keyword similarity retrieval mechanism in `src/services/ai/retrieval.service.js`. However, Atlas Vector Search is recommended for optimal semantic accuracy in production.
